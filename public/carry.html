Carry = the overnight interest-rate differential between the base and the quote currency, annualized for the LONG position. Blue = the long earns, red = the long pays. The scale saturates at ±5.00 pp. Wednesday night's rollover counts ×3 because it covers the weekend settlement — except USD/CAD, which settles T+1 and triples on Thursday. Excludes the broker's markup, which is deducted in both directions.
